## 1. 目标与边界

**目标**：PC 浏览器里放任何视频/直播（不限站点），AI 同步看到画面、听到声音，能边看边说。

**只看屏幕**（唯一不挑站点的路，沿用交接文档结论）。

不做：
- see-now 的悬浮窗
- 界面开关（手动建会话 + 对话里触发）
- 下载视频 / 靠浏览器扩展上报坐标

## 2. 架构：一个采集服务，两个消费者

```
PC 采集服务（独立进程，node + python 子进程）
  ① 画面门控   抓窗口 → 缩 480p → 块差分 → 事件
  ② 声音       环回录音 → VAD 切句 → 转写 → 文本事件
  ③ 按需高清图 原生区域抓图（12–25ms），只在被请求时抓
        ↓
  统一事件队列 events.jsonl（id 单调递增，画面与语音同序列，只带数字和路径）
        ↓
  HTTP + WS 服务（仅局域网）
        ↓                    ↘
  电脑端 agent（读文件/长轮询）   手机端插件（WS 订阅 + HTTP 拉图）
```

**关键解锁**：交接文档说"桥只走文字、传不了图"。但图片不需要过桥 ——
手机插件是原生插件，能自己发 HTTP 请求拉图。桥只用来送"开始/停止"这类控制字，不搬数据。
所以"按需看高清图"这条路是通的。

## 3. 事件格式

```json
{"id":42,"t":12.4,"kind":"motion","strength":"medium",
 "where":"62%,88% dark","scene":"black40%[8,9] blue12%[4,2]",
 "edgeDensity":18,"blocks":[{"x":20,"y":16,"v":14.2}],
 "frame":"data/frames/ev_042.png"}
{"id":43,"t":13.0,"kind":"speech","text":"这道题先配方再开方",
 "t0":12.2,"t1":14.0}
```

- 画面事件**永远不带像素**，只带位置、强度、色块描述 + 一张可选的帧路径。
- 语音事件带起止时间，方便跟画面事件对齐时间轴。
- `id` 跨进程续号（高水位线文件），客户端拿旧 `sinceId` 会被纠正而不是静默漏读。

## 4. 本机实测基线（2026-11-21，4K 屏 3840×2160）

| 环节 | 实测 | 结论 |
|---|---|---|
| 整屏 → 480p | 65–72 ms | 太慢，且字认不出。**不用整屏** |
| 1280×720 → 480p | 11.5 ms（87 fps 上限） | 富余 |
| 1920×1080 → 480p | 22.3 ms（45 fps 上限） | 8fps 只占 18% 单核 |
| 2560×1440 → 480p | 29.5 ms（34 fps 上限） | 也够 |
| 区域原生 1280×720 | 14.8 ms | 字清楚可读 |
| 区域原生 1920×1080 | 25.3 ms | 字清楚可读 |
| 系统声音环回 | 已录到 440Hz 测试音（peak 0.044） | 通了 |

- 环境：node v22.22.2 · Python 3.13.14 · ffmpeg/ffplay 有 · RTX 5080 16G · koffi 已装
- 声音：Python `soundcard`（WASAPI 环回）+ numpy 已装可用
- **未验证**：ASR（faster-whisper/CUDA）还没装，是本方案唯一没跑过的环节

## 6. 沿用的硬约束（交接文档 §5，不推翻）

1. 只做 Wi-Fi 推流，ADB 反连只留记录
2. 不设界面开关，手动建会话后对话里触发
3. 开监听必须超时自动关（防占端口）
4. 换网/断线：报错退出 + 存日志，**不自动重试**
5. 采集与推送分离（同一台机器内部怎么采，跟推到手机无关）

## 7. 风险与未决

- **手机插件我装不了**：我在电脑侧，只能给源码 + 安装步骤，需要你在手机上执行。
- **ASR 是唯一没验证的环节**：faster-whisper 要挂 CUDA（cuDNN 9 + cuBLAS），可能踩环境坑；退路是 CPU int8 small（慢但能用）。
- **音频输出设备要选对**：现在默认走 Realtek 扬声器；如果视频声音走 HDMI/蓝牙，环回设备要跟着切，得做成配置项。
- **桥的真实能力**：交接文档说"只走文字/目录"，我没法在这台机器上验证（插件在手机上）。

## 8. 验收标准

- 1080p 视频窗口，8 fps 采样，连续 10 分钟不崩、CPU 单核 < 40%
- 静止画面 0 事件；换镜头/字幕变化能出事件，一条事件 `< 300` 字符
- 语音延迟（说完 → 出现在事件队列）< 3 秒
- 手机端断网后：服务端报错退出并留日志，不自动重连
- 按需拉一张 1080p 图 < 1 秒（含传输）
