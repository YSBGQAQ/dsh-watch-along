# 12: ASR 覆盖率达标验证

**What to build:** 证明"连续录音"真正解决了丢音频，并与字幕文件对照给出可复现的覆盖率。

**Blocked by:** 05

**Status:** 未达标（64% vs 75%），重复项已清零

- [x] 日志出现 `开始连续录音：扬声器 (Realtek High Definition Audio)`
- [ ] `curl -s http://127.0.0.1:8766/` 返回的 `device` 是**正在出声的那台**
- [x] 播 8.5 分钟，`t0` 从 3.25 单调涨到 513（绝对时间正确）
- [ ] 覆盖率 ≥75% —— **实测 63.6%**（上轮 52%，有提升但未达标）
- [ ] 相似度 ≥0.80 —— **实测 0.739**（比上轮 0.819 低：句子变短，字符级比例被惩罚）

## 已知风险（跑之前先知道）

- 音量为 0 / 默认设备不对 → 全程静默，且**不报错**（表现是 rms≈0）
- 新加的幻觉词表可能误杀正常对白（词表里有"翻译""制作"）

## 验收不过时的下一步
覆盖率仍低 → 转票 13（每段音频只转一次）；误杀明显 → 收紧词表匹配方式。

## 实测（2026-11-21 12:22，8.5 分钟，与 B 站字幕对照）

| 指标 | 上轮 | 本轮 | 说明 |
|---|---|---|---|
| 重复句 | 26 | **0** | 结构性修法生效 |
| 覆盖率（仅文本） | 52% | **63.6%** | 有提升，未达 75% |
| 相似度 | 0.819 | 0.739 | 句子变短 → 字符级比例被惩罚（不是变差） |
| 最佳偏移 | 45s | 75s | 我们的时钟从服务启动算，与视频起点差 75 秒 |

**覆盖率没到 75% 的可能原因（按嫌疑排序）**
1. **幻觉过滤误杀短句**：45 条只有 1–3 字；`_looks_hallucinated()` 里"归一化后不足 2 字即丢"
   会吃掉"走""啊""嗯"这类真实台词
2. **同音字**：`临海市`→`林海志`、`帧`→`针`；没给 `initial_prompt` 专有名词
3. 轻声/气声对白（这类片子里很多耳语）

**下一步建议**：先放宽第 1 条（只在"整句只有 1 个字且不在白名单"时才丢），几乎零成本；
再考虑把片名/地名塞进 `initial_prompt`。
