# 05: 声音通道

**What to build:** 系统里有人说话，一秒之内它变成一条 `speech` 事件，带这句话的起止时间与文本。静音不出事件，套话被挡掉。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 系统静音 10 秒产生 0 条 `speech` 事件
- [ ] 说一句话（结束后）1 秒内出现 `speech` 事件，带 `text` / `t0` / `t1`
- [ ] 「谢谢观看」「字幕由…提供」这类输出被过滤掉
- [ ] BGM 铺满（动态范围 < 6 dB）时不把人声切光
- [ ] GPU 不可用时该通道返回 `failed` 且带 `reason`，不返回空字幕冒充成功
- [ ] 时间码用墙上时间，中间静音 5 秒后下一句的时间不漂移
