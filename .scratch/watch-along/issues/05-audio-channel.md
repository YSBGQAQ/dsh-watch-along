# 05: 声音通道

**What to build:** 系统里有人说话，一秒之内它变成一条 `speech` 事件，带这句话的起止时间与文本。静音不出事件，套话被挡掉。

**Blocked by:** 02

**Status:** ready-for-agent

- [ ] 系统静音 10 秒产生 0 条 `speech` 事件
- [ ] 说一句话（结束后）1 秒内出现 `speech` 事件，带 `text` / `t0` / `t1`
- [ ] 「谢谢观看」「字幕由…提供」这类输出被过滤掉
- [ ] BGM 铺满（动态范围 < 6 dB）时不把人声切光
- [ ] GPU 不可用时该通道返回 `failed` 且带 `reason`，不返回空字幕冒充成功
- [ ] 时间码用墙上时间，中间静音 5 秒后下一句的时间不漂移

## 实跑记录（2026-11-21 09:02）

- [x] 环回录音可用（WASAPI，默认扬声器 Realtek）；`rms=0.10` 说明抓到了真实声音
- [x] GPU 推理可用：装 `nvidia-cublas/cudnn/nvrtc` 后把 `site-packages/nvidia/*/bin`
      挂进 `os.add_dll_directory`，否则第一次 encode 抛 `cublas64_12.dll is not found`
- [x] 真实人声转写正确：「真的非常感谢你们给我的支持」（t0 5.5 / t1 7.96）
- [x] **性能达标**：常驻服务稳态 **687ms / 8 秒音频**（约 11.6× 实时）
      —— 冷启动那次 17.8 秒是 CUDA 上下文初始化，别拿 `--once` 的数字做判断
- [ ] 未接线：`speech` 事件还没进队列（JS 侧照字幕通道的模子写）
- [ ] 未验：BGM 压过人声、唱歌被当说话

**一句话**：功能与性能都成立，剩下的是接线。
