## 收口时的四个已知限制

1. **票 12 的覆盖率目标没达标**（85.9% vs 目标更高），根因是整段 ASR 的分段策略，用户决定收口
2. **票 16 没做**：图仍直接进主会话，长会话会越来越贵（当前 ¥1.2/小时，还能接受）
3. **票 15 的 setup 没在干净机器上跑过**
4. **票 17 的设置项没接到线上**（`audioSource` 目前只落盘，真正生效的是服务端环境变量）
